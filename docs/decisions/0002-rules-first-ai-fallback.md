# ADR-0002：规则优先，AI 只做语义兜底

- 状态：接受
- 日期：2026-08-17

## 决策

常用命令由 HA Assist 自定义句式或 Intent Router 本地规则确定性识别。只有规则未匹配或存在语义歧义时才调用 MiniMax。模型只输出受约束意图，不直接获得 HA 服务调用权限。

## 原因

- 常用控制延迟更低，断网时仍可执行。
- 降低 API 成本和外部云故障影响。
- 让危险动作可被固定规则与确认策略约束。
- MiniMax 可替换为其他兼容提供方，而无需改设备执行层。

## 代价

- 需要维护少量高频中文句式和别名。
- 需要契约校验与策略层，不能把模型输出直接转发。
