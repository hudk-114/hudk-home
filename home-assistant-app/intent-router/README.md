# HUDK Home Intent Router App

本目录提供仓库内 Node.js Intent Router 的 Home Assistant App 清单。

App 默认从 `swr.cn-east-3.myhuaweicloud.com/hudk-home/intent-router:<version>` 拉取 `amd64` 或 `aarch64` 镜像；GitHub Actions 同时发布 `ghcr.io/hudk-114/hudk-home-intent-router:<version>` 作为备用源。发布前，本目录版本必须与 `intent-router/package.json` 一致。
